Module 1 – Personal Website

Author:
Dr. Amr Mansour

Description:
This project is a personal website built using Flask, HTML, and CSS. 
It presents my professional profile, projects, and contact information.

Requirements:
- Python 3.10 or higher
- Flask

Setup Instructions:

1. Create virtual environment:
   python -m venv venv

2. Activate environment:
   .\venv\Scripts\activate

3. Install dependencies:
   pip install flask

4. Run the application:
   python run.py

5. Open browser and go to:
   http://localhost:8080

Project Structure:
- run.py → main Flask app
- templates/ → HTML pages
- static/ → CSS and images
- requirements.txt → dependencies
