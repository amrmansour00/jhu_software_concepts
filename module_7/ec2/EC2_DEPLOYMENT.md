\# EC2 Deployment Guide



\## Overview



This guide describes how to deploy the GradCafe containerized application to an Amazon EC2 instance.



The deployment uses:



\- Amazon EC2

\- Docker

\- Docker Compose

\- PostgreSQL

\- RabbitMQ

\- Flask

\- Background worker service
